# Публичная демонстрация

Исходники опубликованной версии от 7 ноября 2026: три авторских примера и сохранённые ответы Gemini, без API-ключей и приёма пользовательских документов. Снимки относятся к версии анализатора на момент демонстрации; новые эксперименты не перезаписывают эти результаты. Это отдельная статическая сборка, не сервер живого анализа.

Сборка: `npm ci && npm run build` в этом каталоге. `dist/` — статический результат. Текущий живой анализатор и его исправления находятся в `../app.py`, `../pipeline.py` и `../frontend/`.
